# AGENTS - FreakingJSON Public Runtime

Si un modelo de IA lee este archivo, debe operar como asistente del framework publico.

## Reglas publicas

- prioriza archivos locales del repositorio antes de asumir
- usa skills existentes antes de crear soluciones ad-hoc
- protege privacidad: no expongas credenciales, tokens ni datos sensibles
- preserva hallazgos utiles en archivos locales permitidos
- evita mencionar proyectos internos, rutas privadas o procesos de desarrollo internos

## Uso recomendado

1. lee `README.md`
2. consulta `core/skills/SKILLS.md`
3. usa scripts y skills publicas disponibles
4. mantén respuestas claras, utiles y orientadas a uso del framework

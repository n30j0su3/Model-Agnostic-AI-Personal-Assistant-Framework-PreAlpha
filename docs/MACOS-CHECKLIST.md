## macOS-Specific Checks

### Python Paths

| Architecture | Path | Status |
|--------------|------|--------|
| Apple Silicon (M1/M2/M3) | `/opt/homebrew/bin/python3` | ✅ Standard |
| Intel Macs | `/usr/local/bin/python3` | ✅ Standard |
| System Python | `/usr/bin/python3` | ⚠️ Deprecated macOS 12+ |

**Recommendation**: Framework should NOT hardcode Python path. Use:
```python
import sys
python_path = sys.executable  # Dynamically resolved
```

## launchd Integration

### plist Structure (Generated by cron_setup.py)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "...">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.freakingjson.pa-framework.{job_name}</string>
    <key>ProgramArguments</key>
    <array>
        <string>{python_path}</string>
        <string>{script_path}</string>
    </array>
    <key>StartInterval</key>
    <integer>{interval_seconds}</integer>
    <key>StandardOutPath</key>
    <string>{log_file}</string>
    <key>StandardErrorPath</key>
    <string>{error_file}</string>
</dict>
</plist>
```

### launchctl Commands

| Command | Purpose | Status |
|---------|---------|--------|
| `launchctl load ~/Library/LaunchAgents/{plist}` | Load job | ✅ Standard |
| `launchctl unload ~/Library/LaunchAgents/{plist}` | Unload job | ✅ Standard |
| `launchctl list | grep pa-framework` | List jobs | ✅ Standard |

### plist Location

| Location | Use Case | Permissions |
|----------|----------|-------------|
| `~/Library/LaunchAgents/` | User-level cron | ✅ No sudo |
| `/Library/LaunchAgents/` | System-level | ⚠️ Requires sudo |
| `/Library/LaunchDaemons/` | Root-level | ❌ Not needed |

**Framework uses**: `~/Library/LaunchAgents/` (user-level, no sudo)

## Known macOS Edge Cases

1. **System Python deprecated** — macOS 12+ removed system Python. Users need Homebrew Python.
2. **Case-sensitive APFS** — Rare but possible. Framework handles via `Path` operations.
3. **Sandbox restrictions** — Not relevant for CLI tools run from Terminal.
4. **launchd Requires Login** — Jobs only run when user is logged in (vs cron which could run always).

---

## Recommendations

1. **Test on real macOS machine** — M1/M2 preferred (Apple Silicon most common now)
2. **Add macOS CI** — GitHub Actions with `macos-latest`
3. **Document Homebrew Python setup** — Add to README
4. **Test launchd plist generation** — Verify XML is valid
5. **Handle Python path dynamically** — Don't hardcode `/usr/local/bin/python3`

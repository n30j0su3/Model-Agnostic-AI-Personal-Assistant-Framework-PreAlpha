# Release v0.4.1-beta — Local-first, contrato alineado

> Fecha: 2026-10-18 · Predecesor: v0.4.0-beta · Rama: `fix/v041-publication-w0` · Tag: `v0.4.1-beta`

## Resumen ejecutivo

Release de hardening de publicación. El framework mantiene su promesa local-first y model-agnostic, y cierra la deuda que impedía un release repetible: protección de datos, migraciones seguras, cold start veraz, portabilidad Windows, harness idempotente y contrato explícito con OpenCode.

**Beta pública.** No se declara estabilidad universal; Windows nativo sigue en QA.

## Qué cambia para el usuario

- **Tus datos quedan protegidos.** La lista de rutas protegidas es add-only; una actualización no puede quitar los defaults que protegen `data/user`, `data/sessions.db` y `data/user_memory.db`.
- **Las migraciones no pisan tu trabajo.** Si un archivo existe, se conserva y se reporta `[KEEP]`.
- **`workspaces/content` legacy no se borra.** Si ya no está en tu selección, el instalador te informa su ruta y lo conserva.
- **El arranque dice la verdad.** El receipt guarda el storage real, no un `false` por carrera de inicialización.
- **Windows cp1252 deja de romper.** Los scripts programados y los launchers manejan UTF-8.
- **`pa.sh` funciona.** LF, modo ejecutable y flags `--help`/`--version` antes del instalador.
- **La suite se puede repetir.** `.pytest_cache` es scratch; dos corridas en la misma extracción pasan.
- **Symlinks sin Developer Mode.** El test positivo hace skip en hosts sin privilegio; CI exige la capacidad.
- **SQLite se reporta por capacidad.** `sqlite_available:true` sin crear la DB en bootstrap.
- **OpenCode alineado.** Gate `>=1.18.0`; `.opencode/package.json`/lock son runtime-managed y se validan por contrato semver.

## Cómo instalar

**Windows x64:** extrae en `C:\PA` y ejecuta `pa.bat`.
**macOS arm64 / Linux x64:**

```bash
unzip pa-framework-0.4.1-beta.zip -d PA
cd PA
chmod +x pa.sh
./pa.sh
```

Requisitos: Python 3.11+ y OpenCode >= 1.18.0.

## Cómo actualizar desde v0.4.0-beta

```bash
python core/scripts/update.py
python core/scripts/system_check.py
```

Datos preservados: `workspaces/`, `core/.context/`, sesiones, backups, knowledge, configuración y logs.

## Migración desde versiones anteriores

- **v0.4.0-beta → v0.4.1-beta:** ruta automática con `python core/scripts/update.py`; el updater crea snapshot y restaura el estado protegido.
- **v0.3.x → v0.4.1-beta:** mismo updater, pero revisa `python core/scripts/migrate.py --check` y confirma perfil, workspaces, sesiones y modelo después.
- **v0.2.x o anterior / update fallido:** instalación limpia + restaurar `core/.context/`, `data/user`, `data/sessions.db`, `data/user_memory.db` y `workspaces/`; luego `migrate.py --apply`.
- **Rollback:** `python core/scripts/rollback.py --snapshot data/backups/pre-migration-<timestamp> --json`.

Guía completa, con backup, verificación y troubleshooting: [GUIA-DE-MIGRACION-v0.4.1-beta.md](../GUIA-DE-MIGRACION-v0.4.1-beta.md).

## Detalle técnico

### W0 — Baseline

- Base RC6 `b4abe6d0`; tree `732f1ed1`.
- Pin de OpenCode congelado en 1.4.6 (decisión posteriormente revisada en W8).

### W1 — Protección de datos

- Lista canónica de rutas protegidas; loader add-only; seed sincronizado.
- Migraciones `[KEEP]`; no sobrescriben archivos existentes.
- Aviso de `workspaces/content` legacy y conservación del directorio.

### W2 — Cold start

- Receipt con storage real: SQLite, Wiki, MD memory, sesiones.
- `check_sqlite` reporta capacidad sin crear la DB.

### W3 — Encoding Windows

- Helper de consola compartido; scripts programados no abortan en cp1252.
- Launchers activan UTF-8.

### W4 — Harness y portabilidad

- Probe de symlinks; skip por capacidad.
- Fallback no-git fail-closed; escritores aislados.

### W5 — Deuda menor

- Footer de navegación, `utcnow`, tamaños sub-KiB, docstring duplicado, CHANGELOG 22→20.

### W6.1 — Launcher POSIX

- `pa.sh` LF, 100755, flags informativos.
- Gate de CI: `bash -n`, `test -x`, `./pa.sh --help`.

### W7 — QA repetible

- `.pytest_cache` fuera de `RUNTIME_RESIDUE`.
- `PA_FRAMEWORK_DATA` aislado; `_residue_ignore()` compartido.
- `workspaces`/`backlog.md` fail-closed.
- `mtime +1 s` para NTFS.
- Symlinks: skip local + capacidad obligatoria en CI.

### W8 — Contrato OpenCode

- Gate `OPCODE_MIN_VERSION=(1,18,0)`.
- `.opencode/package.json`/lock runtime-managed; manifest schema 2.
- 385 archivos hasheados + 2 volátiles con contrato.
- Pin guard valida coherencia CLI↔plugin, no bytes.

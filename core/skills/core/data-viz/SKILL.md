# Data Visualization Skill

Permite al asistente crear representaciones visuales de datos locales.

## Comandos

- "Genera un gráfico de barras de mis gastos mensuales."
- "Visualiza la tendencia de tokens usados en el último mes."

## Scripts

- `scripts/viz_handler.py`: Handler de generación de gráficos con Matplotlib/Seaborn.

## Uso

```bash
python core/skills/core/data-viz/scripts/viz_handler.py --help
```
